# Idiom Path · 100 идиом

[Открыть приложение](https://evgk724.github.io/idiom-path/) · [QR-код](https://evgk724.github.io/idiom-path/assets/install-qr.png)

100 идиом и устойчивых выражений для взрослого учащегося, который переходит от B1 к B2: оригинальные русские объяснения, контекстные иллюстрации, 200 записей Microsoft Ryan и спокойные тренировки на воспроизведение.

## Установка

В Safari: «Поделиться» → «На экран Домой». Откройте новую иконку при подключённом интернете и дождитесь «Готово без интернета» под верхней панелью. Все материалы, картинки и записи сохраняются заранее. После этого профиль и вход в ChatGPT не нужны; приложение работает без сети. Очистка данных сайта браузером требует повторного сохранения.

## Как учиться

- Первое знакомство: образ, точное значение, простой пример.
- Повторение: ситуация, пропуск в контексте или аудио; ответ и картинка сначала скрыты.
- После попытки — полный ответ и пояснение. «Ещё раз», «С подсказкой» и «Вспомнил сам» управляют датой возврата.
- Новые выражения добавляются небольшими порциями вместе с повторением знакомых. Прогресс и свои примеры хранятся на устройстве; резервная копия доступна в разделе «Память».

Ступени 40/40/20 — порядок обучения и сложность примеров, не официальный CEFR-рейтинг каждой идиомы. Некоторые общеупотребительные идиомы словари относят к более высоким уровням. Научные источники, проверенные 18.10.2026, и ограничения доступны внутри приложения. Интервалы 1/3/7/14/30/60 дней — практическое правило, не универсальный научный оптимум. Увеличение интервала учитывает реальные отметки; повтор в тот же день не повышает уровень. Процент «освоения» и фиктивная история не используются.

## Технически

Статическое приложение без сборщика и внешних runtime-зависимостей. GitHub Pages публикует `docs/` из `main`.

Локально: `python3 -m http.server 4175 --directory docs`.

После изменения ресурсов: обновите VERSION в `docs/offline.js` и `scripts/sw-template.js`, затем `python3 scripts/build-offline.py`. Для аудио используется точный голос `en-GB-RyanNeural`, сведения о генерации и контрольные суммы находятся в `docs/audio/manifest.json`.

Иллюстрации созданы специально как смысловые мнемонические сцены, а не исторические сведения о происхождении идиом. Все примеры написаны для этого учебного приложения; ссылки на словари даны отдельно. Пользовательские заметки никогда не отправляются на сервер.
